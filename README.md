# AnimeIn 🎥

AnimeIn is a modern Android client application designed for cataloging, exploring, and streaming video content. The project is built using modern Android development practices and structured with Clean Architecture.

## 🚀 Features
*   **Modern Catalog UI:** Explore categorized content directly from the dashboard.
*   **Search & Filters:** Search for titles and filter through categories/genres.
*   **Immersive Media Player:** Native video player integration utilizing Jetpack Media3 for smooth stream delivery.
*   **Watch History & Cache:** Local progress tracking and content caching to ensure quick load times.
*   **Material 3 Design:** Built fully using Jetpack Compose with a sleek dark-themed UI.

## 🛠️ Architecture & Tech Stack

*   **Language:** Kotlin
*   **UI Framework:** Jetpack Compose (Material 3)
*   **Architecture:** MVVM (Model-View-ViewModel) + Clean Architecture
*   **Dependency Injection:** Hilt
*   **Local Storage:** Room Database (History, Bookmarks) & DataStore Preferences
*   **Media Playback:** AndroidX Media3 (ExoPlayer)
*   **Network:** Retrofit & OkHttp
